# Planning workflow

- Follow [repo planning guidance](../../../AGENTS/AGENTS_planning.md).
- Keep `master.md` as the roadmap, `0_async_hardening-plan.md` as the overall checklist, and `0_async_hardening-notes.md` as shared decisions and the numbered hardening register.
- Create `phase_A/`, `phase_B/`, etc. just in time, with `phase_A_plan.md` and `phase_A_notes.md` (matching the phase letter); seed them from the overall documents, then elaborate there.
- Keep phase plans succinct and put detailed findings, decisions, and verification evidence in phase notes. Cross-reference stable hardening issue numbers; maintain completion in the shared register and keep overall phase status aligned.
- Use 🔳/✅ status markers. Create only the current phase folder; retain earlier phase records and avoid duplicating shared registers.
